# Memory

A small memory card game built with React and [Vite](https://vite.dev).

## Scripts

- `yarn start` runs the dev server at http://localhost:5173.
- `yarn test` runs the tests with Vitest in watch mode (`yarn test --run` runs them once).
- `yarn build` builds the app for production into `build/`.
- `yarn preview` serves the production build locally.

Uses Node 24 (see `.nvmrc`).
